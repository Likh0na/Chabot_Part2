# Godfather
Custom Class Components: Integrates custom modular mechanics such as `user_name` validation, user greetings (`voice_greeting`), and an extensible response ecosystem (`respond`).
Persistent Interest Tracking: Dynamically checks and saves user interests to a localized text database (`interested_topic.txt`), appending and filtering duplicate topics cleanly.
Proactive Engagement: Automated reminder systems tracking conversation metrics (`auto_show_interest`) to remind users of topics they care about.
Robust Input Sanitization: High-performance Regex-based parsing to remove disruptive special characters while safely preserving sentence structure.
Dynamic UI Layouts: Distinct structural visual styles (colors, border variations, word wrapping) differentiating messages between the User and the ChatBot.
